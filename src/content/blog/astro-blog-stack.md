Astro 很适合个人博客这类内容型网站。

它默认输出静态页面，加载速度快，对 SEO 友好，也可以直接用 Markdown 或 MDX 写文章。对于个人博客来说，这些能力比复杂的后台系统更重要。

## 这个技术栈的优势

1. 页面快，部署简单。
2. 内容结构清晰，文章可以直接放在 `src/content/blog`。
3. 后续可以继续添加 RSS、站内搜索、评论、标签和归档。
4. 不需要一开始引入数据库和后台系统。

## 当前目标

先搭好基础版本，让网站能够本地运行、正常构建，并且可以部署到 Vercel 或 Cloudflare Pages。
